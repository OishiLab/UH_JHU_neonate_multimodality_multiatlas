# UH_JHU_neonate_multimodality_multiatlas
Neonatal brain MRI atlas repository containing T1-weighted, T2-weighted, and diffusion tensor imaging (DTI) data from 7 infants, with anatomical parcellation maps derived from T1- and T2-weighted images. The dataset supports neonatal brain segmentation and multi-atlas label fusion (MALF). Otsuka et al., J Neuroimaging, 2019. DOI: 10.1111/jon.12623.
